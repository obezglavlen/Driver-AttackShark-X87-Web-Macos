Firmware-fixed: media normal, F keys with Fn.

Windows mode is configurable here and auto-syncs when the switch is in Win. Mac mode is fixed by the keyboard firmware: media normal, F keys with Fn. Use Windows mode on macOS if you want F keys primary. F1–F12 are managed here; individual F-row remaps in the key editor are replaced by the sync.

Select a key

Media entries send standard consumer keys. Mac shortcuts include Spotlight (Cmd+Space), App Switcher, Mission Control, screenshots, etc. Dictation and Sleep are not standard HID keys on macOS; they require a custom macOS shortcut or a third-party remapper, so they are not offered here.

Backup & restore

The original configuration was saved before any write. You can also create a new full dump at any time.

Safety

  • Wired USB-C only. Do not configure over the 2.4 GHz dongle or Bluetooth.
  • No firmware update command is implemented.
  • Every write saves the previous block to profiles/ and verifies the readback.
  • Factory reset on the keyboard: hold Fn + Esc for about 3 seconds.
